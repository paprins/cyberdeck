Cyberdeck Architecture — Section 1: System Overview

Option A: FastAPI portal + Kiwix-serve sidecar

Display Layer

Chromium Kiosk auto-start

Full-screen browser pointed at localhost:8000. Touch + keyboard input. Family members interact here.

↕
Application Layer

FastAPI Portal App port 8000

  • Home portal — category tiles (Medical, Maps, Survival, Food…)
  • Unified search — queries Kiwix + local content
  • Package manager — check updates, resumable downloads, install
  • Reverse proxy — routes /wiki/* → Kiwix-serve, /maps/* → tile server
  • Power management — display dimming, CPU governor control
↕
Content Services (managed subprocesses)

Kiwix-serve port 8080

Serves ZIM files. Handles Wikipedia curated subset, medical references, survival guides, food/nutrition content.

mbtileserver port 8081

Serves OpenStreetMap vector/raster tiles from .mbtiles files. Supports regional + world-level maps.

↕
Storage — 1TB SSD

/data/zim/

ZIM content packs (Wikipedia subset, Wikivoyage, medical, survival, food)

/data/maps/

OpenStreetMap .mbtiles files (regional or world)

/data/downloads/

Partial + completed package downloads. Resumable state persisted here.

/data/packages/

registry.json — tracks installed packages, versions, checksums

↕
OS Layer

Raspberry Pi OS Lite (64-bit) headless base

Systemd manages all services. CPU governor set to conservative. Display managed via sysfs backlight. WiFi managed via NetworkManager for update connectivity.
